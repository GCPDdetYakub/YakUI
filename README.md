# YakUI

YakUI позволяет ставить плагины из Rhino Packages (PackageManager) без запуска Rhino. Это простая оболочка для оригинального консольного инструмента `Yak.exe` от McNeel, но всё ещё требует от вас предварительного обхода региональных ограничений.

## Как пользоваться

1. Откройте YakUI.
2. Найдите плагин в каталоге.
3. Нажмите «Установить».
4. Откройте Rhino — плагин уже там.

Плагин скачан с сайта (Food4Rhino, GitHub) или прислан коллегой? Перетащите файл в окно YakUI — он сам всё поставит. Разблокировать архив вручную не нужно.

## Функции

* Каталог плагинов с поиском и фильтром совместимости для каждой установленной версии Rhino
* Установка, обновление, откат и закрепление версий плагинов
* Установка сразу в несколько версий Rhino
* Установка в стандартную папку Rhino или в свою папку, с созданием ссылки `.ghlink` в папке Libraries
* Сторонние плагины — `.zip`, `.gha`, `.yak` и целые папки — ставятся на выбор:
  * **«В Rhino как пакет»** — как плагин из каталога, в выбранные версии Rhino; YakUI сам собирает пакет штатным `yak`, версию берёт из плагина или по дате его сборки;
  * **«Grasshopper Libraries»** — одна копия для всех версий Rhino;
  * **«Своя папка»** — например, общая папка отдела.
* Копируется всё содержимое архива; метка «скачан из интернета» снимается со всех файлов
* `.yak`, скачанный из Rhino Packages, распознаётся и ставится как плагин каталога, с проверкой обновлений
* Экран «Установленные» разделён на две части: **Package Manager** (плагины из каталога, с проверкой обновлений) и **Сторонние**; можно выделить несколько и удалить разом
* Чистое удаление: YakUI удаляет ровно те файлы, которые поставил
* Обновление `Yak.exe` для каждой версии Rhino (если они в открытом доступе)
* Предупреждение, если в Rhino включено автообновление плагинов
* Журнал: что, когда и куда ставилось
* Проверка новой версии YakUI на GitHub — внизу окна появится «Доступна YakUI X ↗»

Windows 10/11, Rhino 7 или 8.

## Сборка

```
powershell -ExecutionPolicy Bypass -File build\publish.ps1
```

Результат в `artifacts\`: `YakUI-<версия>-win-<arch>-setup.exe`, `YakUI-<версия>-win-<arch>-portable.zip`, `SHA256SUMS.txt`.

# YakUI — структура папок при установке

`%LOCALAPPDATA%` = `C:\Users\USERNAME\AppData\Local`, `%APPDATA%` = `C:\Users\USERNAME\AppData\Roaming`.

## 1. Сама программа

```
%LOCALAPPDATA%\Programs\YakUI\      ← папку можно сменить при установке
├─ YakUI.exe                        ← окно программы
├─ YakUI.Cli.exe                    ← консольная версия (команды list, install…)
├─ *.dll                            ← библиотеки .NET и Avalonia
└─ unins000.exe                     ← удаление программы
```

- Ставится **только для текущего пользователя**, без прав администратора.
- Ярлык в меню «Пуск», на рабочем столе — по галочке.
- Запись в «Параметры → Приложения», оттуда же удаление.

## 2. Настройки (появляются при первом запуске)

```
%APPDATA%\YakUI\
└─ settings.json                    ← тема, язык, папки, фильтры, hosts-строки и т.д.
```

## 3. Рабочие данные (появляются по ходу работы)

```
%LOCALAPPDATA%\YakUI\
├─ yakui.db                         ← база: кэш каталога, журнал, закрепления, реестр установок
├─ state\                           ← копии важных данных вне базы (реестр установок, загрузок и др.)
├─ icons\                           ← иконки пакетов (кэш)
├─ downloads\                       ← скачанные вами .yak (папку можно сменить в настройках)
├─ cache\yak\                       ← временные файлы установки, удаляются после успеха
├─ yak\                             ← скачанные версии yak.exe
├─ logs\                            ← технические логи, включая db-open.log
└─ backups\hosts\                   ← копия hosts на время сеанса
```

## 4. Куда YakUI пишет только по команде пользователя

Это уже не файлы YakUI, а установленные им плагины:

| Действие | Куда |
|---|---|
| Стандартная установка и «В Rhino как пакет» | `%APPDATA%\McNeel\Rhinoceros\packages\<7.0 / 8.0>\<Плагин>\<версия>\` |
| «Grasshopper Libraries» | `%APPDATA%\Grasshopper\Libraries\<Плагин>\` |
| Установка в свою папку | `<ваша папка>\<Плагин>\<версия>\` + ссылка `%APPDATA%\Grasshopper\Libraries\<Плагин>.ghlink` |
| `.ghuser` при установке в Libraries или свою папку | `%APPDATA%\Grasshopper\UserObjects\<Плагин>\` (при стандартной установке остаются в папке пакета) |
| Кнопка hosts | `C:\Windows\System32\drivers\etc\hosts` (с UAC), при закрытии YakUI возвращается как было |

## 5. При удалении YakUI

- Папка программы удаляется полностью.
- Установщик **спрашивает**, удалить ли пункты 2 и 3 (настройки, кэш, скачанные файлы, журнал).
- **Установленные плагины Rhino не трогаются** — они остаются и работают дальше.

## ZIP-версия

Устроена так же. Отличие одно: если рядом с `YakUI.exe` лежит файл `portable.flag`, пункты 2 и 3 хранятся не в профиле Windows, а в папке `data\` рядом с программой.
